Student Management System Using AWS

Project Description

A cloud-based web application developed to manage student records using AWS services.

Technologies Used

- HTML
- CSS
- JavaScript
- Python
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- AWS Amplify

Features

- Add student details
- View student records
- Update student information
- Delete student records

AWS Architecture

User → Website → API Gateway → AWS Lambda → DynamoDB

AWS Amplify is used to host the frontend website.

Database

DynamoDB Table: StudentRecords

Fields:

- Student ID
- Name
- Email
- Department
- Year

Advantages

- Easy student record management
- Cloud-based data storage
- Reduces manual work
- Easy access and updates

Future Enhancements

- Student Login
- Admin Login
- Attendance Management
- Marks Management
- Report Generation
